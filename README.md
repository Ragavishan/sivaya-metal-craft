# SIVAYA METAL CRAFT

Premium stainless steel fabrication website built with:

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

## Locked brand palette

- Thistle / Dusty Rose: #EBC9CF
- Deep Teal / Dark Slate: #063737
- Terracotta / Rust: #A25524
- Olive Green: #808000

No additional brand colors are used.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Replace project imagery

Add real project photos inside `public/projects/` and wire them into the Projects section.
